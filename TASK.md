# ЗАДАНИЕ (L3, охота на баги)

В корне лежит `inventory.py` — учёт товаров на складе. В код ЗАКЛАДЕНЫ
РОВНО 3 БАГА (логические, не синтаксические): при каких-то входных
данных программа выдаёт неверный результат.

Задача:
1. Найди все 3 бага (читай код внимательно, прогоняй сценарии).
2. Исправь их в inventory.py (минимальные правки).
3. Напиши `test_inventory.py` (pytest): по тесту на каждый найденный
   баг (тест должен падать на старом коде и проходить на исправленном)
   плюс 2-3 общих теста.

Критерий готовности: `python -m pytest test_inventory.py -q` — зелёный.
Отчёт: перечисли 3 бага одной строкой каждый (где и в чём ошибка).
