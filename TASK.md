# ЗАДАНИЕ: pytest-тесты для recipe_runner.py

## Цель
Написать файл `test_recipe_runner.py` с модульными тестами (pytest)
для чистых функций модуля `recipe_runner.py`, который лежит рядом
в корне репозитория.

## Окружение
- Python 3, установи pytest: `pip install pytest`.
- Тестируемый модуль импортируй как `import recipe_runner as rr`.

## Что тестировать (только чистые функции, без браузера)
1. `_expand(value, recipe, state)` — подстановка `{{key}}`:
   - ключ из recipe заменяется;
   - ключ из state заменяется;
   - отсутствующий ключ остаётся как `{{key}}`;
   - нестроковое value возвращается без изменений.
2. `parse_locate`-подобные regex-сценарии НЕ нужны (их нет в модуле).
3. `_check_absent` НЕ тестируй (нужен браузер).
4. Если в модуле есть другие функции без аргумента `page` —
   покрой их по аналогии (по одному тесту на функцию достаточно).

## Требования к тестам
- Фикстуры не нужны; обычные функции test_*.
- Имена тестов читаемые: test_expand_uses_recipe_key и т.п.
- Запуск: `python -m pytest test_recipe_runner.py -q`.

## Критерий готовности
`python -m pytest test_recipe_runner.py -q` — все тесты зелёные.

## Запреты
- Не изменяй `recipe_runner.py` — только создавай test_recipe_runner.py.
- Не добавляй других файлов.

## Отчёт
В конце ответь одним абзацем: сколько тестов написано, что покрыто,
результат прогона (числа, не «всё ок»).
