# ЗАДАНИЕ (L4, фича в существующий код)

В корне лежит `mini_recipe.py` — исполнитель шагов рецепта (упрощённый).
Нужно ДОБАВИТЬ новый шаг `repeat`:

```yaml
- id: my_step
  action: repeat
  times: 3
  step:
    action: set
    key: counter
    value: "x"
```

Шаг repeat исполняет вложенный шаг `times` раз подряд. Счётчик
итераций доступен вложенному шагу через `{{i}}` (0-based).

Требования:
1. Реализуй repeat в mini_recipe.py (минимальные изменения, стиль как
   у существующего кода).
2. Напиши `test_repeat.py` (pytest): repeat работает, i подставляется,
   times=0 → ни одного исполнения, вложенный шаг set выполняется
   нужное число раз.
3. Обнови docstring модуля одной строкой про repeat.

Критерий готовности: `python -m pytest test_repeat.py -q` — зелёный
и существующие тесты (если будут) не сломаны.
Отчёт: что изменено, строк диффа, результат прогона (числа).
